# GitHub Pages – original-template English version

Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.

Keep index.html and all original asset filenames and their adjacent folder structure in the repository root. After publishing, use a hard refresh or a new private browser window to avoid stale service-worker assets. The translated version uses a separate IndexedDB store from the Hungarian original; old entries remain in the original browser database.

Do not upload field-data spreadsheets or respondent details. Exports are downloaded locally by each institution and should be transferred to the analyst through an authorised channel.
